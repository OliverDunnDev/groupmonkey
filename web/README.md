# GroupMonkey web

React 19 + Vite + TypeScript front end. See the repo root [README.md](../README.md) to run the whole app and
[DEVELOPING.md](../DEVELOPING.md) (section 6) for how this part is organised.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to http://localhost:5080 (override with API_URL)
npm run build
npm run lint
```
